WATER SE MUEVE - sitio estático para GitHub Pages

0) Incluye: ola animada, test "¿Qué torneo sos?" para compartir, botón fijo en celular, formulario incrustado.
1) Completar en index.html el bloque CONFIG (al final del archivo):
   - formUrl, formResponseUrl, entryPreferida, entryPropuesta, entryAspecto: ya cargados (formulario "Propuestas para el house de Water")
   - fecha: fecha de votación (ya cargada: 23 de noviembre)
2) Fotos en la carpeta img/: dupla.jpg (portada, opcional), luca.jpg y elisa.jpg (sección ¿Quiénes somos?). Si falta alguna, se muestra un marcador o se oculta sola.
3) Subir a GitHub:
   - Crear cuenta en github.com > New repository > nombre: water-se-mueve > Public > Create
   - "uploading an existing file": arrastrar index.html y la carpeta img > Commit changes
   - Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Save
   - En 1-2 minutos queda en https://TUUSUARIO.github.io/water-se-mueve/
4) Para cambiar algo después: abrir el archivo en GitHub > ícono lápiz > editar > Commit.
